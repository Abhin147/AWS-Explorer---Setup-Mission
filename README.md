# AWS Explorer - Setup Mission 🚀

## 📌 Overview

AWS Explorer is a simple Python project that demonstrates how to set up and use the **AWS SDK for Python (boto3)**.

The project includes:

- Installing and configuring boto3
- Creating an AWS IAM user
- Assigning read-only permissions
- Configuring AWS credentials securely
- Using Python and boto3 to list AWS regions
- Verifying successful execution
- Following basic AWS credential security practices

---

## 🎯 Objective

The objective of this task is to establish a secure connection between a Python application and AWS using **boto3**, and verify the setup by retrieving a list of AWS regions.
